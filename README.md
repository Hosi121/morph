# morph

MoonBit の代数的データ型・パターンマッチ・再帰でアルゴリズムを組み立てる実験。
手書きのアルゴリズム本体では、組み込み数値型・数値リテラル・配列添字・可変状態を使わない。
Bool、Unit、独自の不変リスト、直和型・直積型から構成する。

```sh
tools/bootstrap             # 初回：既存のグローバル環境には触れず公式配布を取得
tools/moon test
tools/moon test --target js
```

設計、検証範囲、計算量と表現コストの区別は [ハンドブック](HANDBOOK.md) に記録する。
これは数値計算ライブラリの高速化を目的とするものではない。
