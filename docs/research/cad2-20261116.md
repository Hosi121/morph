# 二変数 CAD と量化文の決定

[ドキュメント](../README.md) / [研究・探索記録](README.md)

## 到達点

[cad2](../../src/cad2) は QQ[x,y] の六つの符号関係と Boolean 結合を、
full Collins projection と代数的係数上の lifting で判定する。
変数順序は外側 x、内側 y に固定する。
`eliminate_y` は x の全セルに対応する真偽列を返し、`sentence` は
∃x∃y、∀x∃y、∃x∀y、∀x∀y の文を決定する。
任意変数数、任意の入れ子の量化式、通常の多項式 Formula への出力変換は実装していない。

## 組み立てた経路

1. 元の全 atom を検査し、二変数の arity を固定する。未到達の Boolean 分岐にも検査を行う。
2. [projection](../../src/projection) の full Collins を使い、全係数、全非零 reducta の導関数 PSC、異なる atom の全 reducta 対の PSC を得る。
3. 射影多項式の恒真式を [realcad](../../src/realcad) に渡し、全実 x を符号不変な点・開区間へ分ける。
4. 各 x 標本の Number を [realminimal](../../src/realminimal) で正規化し、Proven の既約因子から選択埋込みの Field を作る。
5. 元の各多項式をその Field に代入し、[relativecad](../../src/relativecad) で y の全根と開区間を分割する。
6. 一つの x セルの y 真偽を先に集約し、その結果を x セル全体で集約する。

原式が x=α で零多項式になる場合も、その atom の符号を0として保持する。
残る atom は独立に lift するので、`x*y=0 AND y>0` の x=0 の半直線を失わない。
同様に、先頭係数が消える点では剰余を取った係数列から実際の次数を再計算する。
共有因子や反復因子を単純な discriminant だけで扱わず、full projector と相対 squarefree Sturm を使う。

## セルの意味と理論の境界

base の各セルの上では、元の atom の根を昇順に追った section と、その間の sector が stack になる。
出力は元の式、base セルの順序、標本での相対根の順序を保つ暗黙のセル表現であり、
根曲線を浮動小数点で描画したデータではない。
投影に関する根拠は、
[Jovanović–de Moura, Solving Non-Linear Arithmetic, §4.1 Definition 2 / Theorem 2 / Lemma 1](https://dddejan.github.io/papers/jovanovic-ijcar2012.pdf)
に記載された Collins operator と、符号不変な base 領域上で realizable sign assignments が一定になる性質に合わせた。
有限の一次元 base は点または連結開区間である。

この幾何学的な定理を Lean へ翻訳した証明はない。
実装は exact projection、数体、Sturm、checker と compiler の正しさを信頼する。
既存の基礎算術や Horner の Lean モデルが、そのまま CAD 全体の形式証明になるわけではない。

## 証拠と資源

Certificate は元の Formula、full projection、base decomposition、各 base 標本と
その最小多項式の証拠、全 fibre decomposition を保持する。
checker は元の Problem から投影を再検査し、全 base セルと同じ順序・個数の stack を要求する。
各 Field の最小多項式の入力をその base 標本に結び付け、元の式を再代入して fibre の全根・符号・真偽を検査する。

Machine は base、次の stack、進行中の相対 CAD を保持する。
燃料0は Paused。分解の prime / Hensel / subset / checker budget が不足すれば NeedsBudget を返す。
`rebudget` で同じ続きの予算を差し替えられ、不足を「解なし」に変えない。
一歩の中の因数分解・多項式算術・投影の費用は一定ではなく、燃料は wall-clock 上限ではない。

## 最初の検証

7 個のテストが native・JS・WasmGC で成功した。

- `x²+y²=2` の有理・無理数の critical x、0/1/2 本の実根と ∃y の全セル真偽。
- `y=x` で ∀x∃y が真、∃x∀y が偽となり、セル全体を flatten しないこと。
- `x*y=0 AND y>0` の nullification。
- `x*y²+y+1` の次数低下、discriminant の根、厳密不等号の端点。
- 共有・反復因子と根の衝突、定数式、未到達の不正 arity。
- NeedsBudget 後の再開、projection・base/stack順序・Field・fibre・元式の差替え拒否。

この第一段階は既知の族から手で導いた期待値との照合である。
実装を見る前に別に作った exact oracle の追加レビューは独立した記録に残す。
検証用ログと source hash は `.tools/cad2-20261116` に保存する。
