# 除算を使わない特性多項式と随伴行列

[ドキュメント](../README.md) / [研究・探索記録](README.md)

## 目的

数体の norm、消去多項式、行列の恒等式で共用できる、環の上の特性多項式を作る。
有理数の行簡約と異なり、逆元を要求しない算法なら整数、多項式環、零因子を持つ環でも同じ核を使える。

実装は [berkowitz](../../src/berkowitz/berkowitz.mbt)。
`Ring[A]` は既存の半環辞書に符号反転を加えたもの。単位的可換環の法則は辞書を渡す側の条件であり、任意の関数について実行時に証明する入口ではない。
整数と有理数用の辞書を同梱する。

## 算法

行列を `A = [[a,R],[S,M]]` に分け、小さい主部分行列 M の特性多項式から再帰的に組み立てる。
下三角 Toeplitz 行列の第一列を
`1, -a, -RS, -RMS, -RM²S, ...` とし、その作用を係数列の切り詰めた畳み込みで計算する。
密な Toeplitz 行列や M の行列冪は構築せず、ベクトル `S, MS, M²S, ...` だけを順に作る。

出力は `det(tI-A)` の次数降順の係数列で、先頭の 1 を含む。
行列式は定数項の符号を次元の偶奇で調整する。
[行列への多項式代入と随伴行列](../../src/berkowitz/matrix_polynomial.mbt)も同じ演算辞書を使い、
`det(tI-A)=t q(t)+c` から `adj(A)=(-1)^(n+1) q(A)` を求める。
特異行列でも随伴行列は返せる。逆行列を返す API ではない。

これは逐次版で、密な n 次行列では O(n⁴) 回の環演算。
係数のビット長、永続リストの走査、任意精度演算の費用は別にかかる。
既存の有理数行列式より速いという採用判断はしておらず、除算できない係数環への適用範囲を増やす。

## 検証

- stdlib `Fraction` と符号付き順列による `det(tI-A)` の展開で、0〜6 次の 73 行列について全係数を独立に比較する。
- 随伴行列は余因子行列の転置を独立に作って照合する。零行列、特異行列、有理係数を含む。
- 3×3 の全 512 Bool 行列を整数上で計算し、Z/2、Z/4、Z/6 への写像と比較する。後二者には零因子がある。
- Cayley–Hamilton の代入が零行列になること、および左右の `A adj(A)=adj(A) A=det(A) I` を検査する。
- 0×0、1×1、長方形、行が空で幅だけ残る行列も入口で区別する。

生成器: [generate_berkowitz.py](../../tools/generate_berkowitz.py)。
外部の特性多項式ライブラリや Berkowitz 実装をオラクルに使わない。
有限のテストであり、環の公理や MoonBit コンパイラまで含む形式証明ではない。
