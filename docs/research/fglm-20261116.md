# F4 基底からの FGLM order change、2026-11-16

[研究・探索記録](README.md) / [F4 実装記録](f4-20261116.md)

有理係数の零次元 ideal について、F4 の lex Gröbner 基底から別の monomial order の reduced 基底へ変換する。変換本体は Buchberger / F4 を再実行せず、有限 quotient の normal-form vector と線形従属を使う。手書き計算核は Bool、不変 ADT、Peano Nat、不変 Chain、クロージャのみで構成する。

[公開 API](../../src/fglm/pkg.generated.mbti)、[FGLM driver](../../src/fglm/fglm.mbt)、[有限 staircase と heap](../../src/fglm/staircase.mbt)、[target order / normal form](../../src/fglm/order.mbt)、[証拠と独立検査](../../src/fglm/certificate.mbt)。

## 入口と対象

- source は `@f4.Basis`。`@f4.variables`、`@f4.polynomials`、`@f4.verify` を読み、F4 本体は変更しない。
- target は `Lex`、`GradedLex`、`GrevLex`。全て第一変数が最大。既存 `Polynomial` の保存順は lex のままで、先頭項の選択と normal form は target order の別実装を使う。
- `convert(source, target, max_dimension, fuel)` は `Complete(Basis)`、`Paused(State)`、`Undecided(DimensionLimit)` のいずれか。`start` / `step` / `run` で再開できる。
- source の先頭 ideal に各変数の pure power がなければ `Err(PositiveDimension)`。不足した dimension cap は `Undecided` と区別する。unit ideal は quotient dimension ゼロとして即座に扱う。
- `polynomials` は target order に関する monic reduced Gröbner 基底。`dimension` は quotient のベクトル空間次元、`standard_monomials` は target order の昇順 monomial basis を返す。
- `certificate` / `verify` / `check` は結果の検査用。`statistics` は処理・独立・従属・prune 数を返す。統計は時間や性能改善を意味しない。

非 radical ideal にも対応する。例えば `⟨x²,y³⟩` は原点しか持たないが quotient dimension は六であり、異なる実根の個数とは区別する。変数ゼロの零 ideal は Q 自身なので次元一、unit ideal は次元ゼロとして検査する。

## 真の FGLM 経路

source の lex 先頭単項式に、各変数の pure power があることを確認する。これが有限 staircase の証拠になる。source standard monomial は persistent leftist heap で一から列挙し、source 先頭項で割れる monomial を prune する。standard monomial だけが変数倍を enqueue する。重複は enqueue 時点で除外するので、大きい Cartesian bounding box 全体を構築しない。

target 側も persistent heap を使い、target order で最小の monomial `m` を取り出す。既に見つかった relation の先頭項の倍なら捨てる。そうでなければ source 基底による `NF(m)` を計算し、source staircase の係数 vector `v` に写す。

これまで target standard とした monomial の NF vectors を**列**とする行列 `A` について、exact rational `A*c=v` を解く。inconsistent なら新しい独立 vector なので `m` を target standard に加え、各変数倍を heap に追加する。unique solution があれば次の relation を追加する。

```text
m − Σ c_i t_i
```

ここで `t_i` は既に選んだ target standard monomial。solve 後も `Σ c_i v_i = v` を別の直接線形結合で確認する。Affine solution は保持済み vectors の独立性に反するので `InternalInvariant` とする。queue が空のとき、選んだ target standard の数が source dimension と一致することを確認して完了する。

この構成は [Faugère–Gianni–Lazard–Mora, 1993](https://www.sciencedirect.com/science/article/pii/S0747717183710515) の quotient-space による order change に基づく。[SymPy の公式 FGLM 実装](https://github.com/sympy/sympy/blob/1.14.0/sympy/polys/fglmtools.py) とも、NF vector・target monomial queue・従属 relation という対応を確認した。本実装は source NF を各候補で計算し、線形 solve を再実行する基本形であり、multiplication matrices の事前構築や incremental elimination を持つ高速実装ではない。

## cap と fuel の意味

`max_dimension` は source standard monomial の数の上限。cap を超す一つ目の standard monomial が見つかった時点で `Undecided(DimensionLimit)` とし、まだ変換したとは主張しない。cap を増やす場合は `convert` / `start` を呼び直す。

fuel は target heap の一回の pop と最後の finalization に一単位。prune された pop も数える。一回の pop は source normal form と exact linear solve を含めるため、fuel を arithmetic operation、ビット演算、時間、メモリの上限と混同しない。source 検証・staircase 構築は fuel の前段。unit ideal は既に決まる特例として fuel ゼロでも完了する。

独立 vector だけが変数倍を追加するので、source dimension D、変数数 n に対して候補の追加数は高々 `1+nD`。これは heap pop の数に関する構造的な制約であり、係数成長や normal-form 計算の費用をそのまま制限しない。

## 線形依存 witness と独立 checker

各 relation には `monomial`、その時点の `standard_monomials`、有理係数列を保存する。公開 certificate はそれらと出力多項式列・target order を持つ。checker は heap や線形 solve を再実行せず、次を検査する。

1. witness が主張する `m − Σ c_i t_i` と出力多項式が完全一致し、各 `t_i` が target order で `m` より小さい。
2. 全 target 多項式が source 基底で零 NF になる。
3. 全 source 多項式が target 基底で零 NF になる。
4. target の全 S ペアが target NF でゼロになる。

二・三が ideal の一致を、四が target order についての Gröbner 性を保証する。witness は依存式を表すもので、単独でその prefix の独立性を主張するものではない。出力の reduced 正規形と standard-monomial metadata は生成器の不変条件および独立 CAS と照合する。

偽の線形係数、欠落した基底、元 ideal より大きい ideal の基底を拒否する。非対称な係数行列で列・行を取り違えると異なる係数になる例、既に従属する vector を状態に入れた場合の拒否も検査する。

## 独立照合

[fixture generator](../../tools/generate_fglm_fixtures.py) は SymPy 1.14.0 の `QQ` で、source lex 基底の `fglm(target)` と target order の直接 Gröbner 基底計算を別々に行い、一致を確認する。source / target 先頭項の pure-power bounds から Cartesian box を独立列挙し、quotient dimension と target standard monomial の**列全体**も固定する。[SymPy の公式 API 文書](https://docs.sympy.org/latest/modules/polys/reference.html#sympy.polys.polytools.GroebnerBasis.fglm) の zero-dimensional order conversion に対応する。

二〜四変数・一変数の固定系十五件と固定 seed の二変数系十二件、計二十七 ideal を三 order へ変換した八十一 fixture に一致。unit ideal、dimension 12 の非 radical ideal、循環対称系、有理係数、同じ quotient でも GradedLex と GrevLex で target standard が入れ替わる三変数系を含む。正次元拒否、cap の一不足、fuel ゼロ / 一段再開、heap 重複除去・relation 倍の prune、公開 API を別 package から使う試験も追加した。

## 残る制約

source order は F4 が出す lex に限定する。全ての admissible order、block order、weighted order、正次元 ideal の Gröbner walk は対象外。dense exact solve と再計算する source NF を使い、係数・証拠の成長もあるため、原論文の高速実装の計算量や他方式への速度優位を主張しない。大規模 staircase の資源限界、機械化した正当性・停止証明、serialization 後の opaque Basis 再構築は未対応。公開 checker はideal の同値性・target Gröbner 性・依存式を検査するが、FGLM の探索履歴を実行したことそのものを証明するものではない。
