# Immutable shape-checked tensor algebra

`tensor` is an independent generic dense component container and algebra. It
stores an explicit `Chain[Nat]` shape and a validated flat row-major `Chain[A]`
in an opaque `Tensor[A]`. The last axis varies fastest. This is shape-level
algebra: the type does not track covariant/contravariant variance, coordinate
charts, symmetry or physical meaning. Geometric callers must supply those
interpretations and choose the appropriate linear maps or contractions.
The existing Riemann nested-chain aliases remain unchanged.

## Construction and exact edge semantics

`from_flat(shape, entries)` succeeds exactly when the entry count equals the
product of axis dimensions. Empty shape has product one and denotes a scalar
with one entry. Any zero-sized axis makes the product zero and requires no
entries. These cases are distinct: shape `[0,0]` is an empty rank-two tensor,
while its trace is shape `[]` with one additive-zero scalar entry.

`tabulate(shape, callback)` visits every valid coordinate in row-major order.
It calls the callback once with empty coordinates for a scalar and never for a
shape containing a zero-sized axis. `shape`, `rank`, `entries`, `map`, and `zip`
retain the explicit dimensions. Zip requires exact shape equality even when
shapes have equal cardinality or both contain zero axes.

`at(t, coordinates)` first checks coordinate rank, then bounds from left to
right. It returns a typed error rather than padding, wrapping, or inventing an
entry. `TensorError` includes `EntryCountMismatch`, `CoordinateRankMismatch`,
`CoordinateOutOfBounds`, `ShapeMismatch`, `AxisOutOfBounds`, `RepeatedAxis`,
`AxisSizeMismatch`, `PermutationRankMismatch`, `PermutationOutOfBounds`,
`PermutationNotBijective`, `ModeWidthMismatch`, and `InternalShape`. The last
is an internal guard, unreachable through checked public constructors and
operations; no panic or machine indexing is used in the kernel.

## Axis algebra

- `permute(t, order)` means output axis j comes from input axis `order[j]`.
  It checks order length, bounds, then uniqueness, establishing a bijection.
  Scalar empty permutations and permutations involving zero axes are valid.
- `product(semiring, left, right)` appends the right shape to the left shape.
  Entries multiply left to right, with the right entry index varying fastest.
- `contract(semiring, t, a, b)` requires two in-range distinct equal-sized axes.
  It sums diagonal entries in increasing axis index; remaining axes retain
  their original order. Bounds are checked before distinctness, then sizes.
  Summing an empty diagonal gives `semiring.zero` for every output coordinate.
- `mode_product(t, axis, linear_map, semiring)` takes `linear_map[out,in]`.
  Its width must equal the selected input axis size; output axis size is the
  map height. It sums coefficient times entry in increasing input-axis index.
  A zero-to-m map gives additive-zero entries where other axes permit entries;
  an m-to-zero map gives an empty tensor with the new zero axis.

The supplied semiring dictionary is assumed lawful; its laws are not proved by
construction. It permits exact rational, Boolean, finite-field and other
component arithmetic without constraining A to a numeric primitive or Eq.
Contraction itself does not verify geometric index variance. Mode products can
apply a Jacobian transpose on covariant axes, but the caller supplies that map.

## Finite independent oracle and limits

The white-box oracle uses host arrays, integer indices and explicit loop sums,
not the kernel's coordinate enumeration, offset, permutation or contraction
helpers. It checks all 40 shapes of ranks zero through three with axis sizes
0/1/2: construction, every valid coordinate, callback ordering/counts, malformed
entry counts, bounds, map and zip. It checks all 184 shape/permutation pairs,
60 valid ordered contractions plus all distinctness/size/bounds failures,
306 rectangular mode products with zero input/output dimensions and width
errors, and all 1,600 ordered small-shape tensor products. Complete output
shapes and entries are checked; no checksum is used. Examples also distinguish
Boolean OR/AND from GF(2) XOR/AND and use the existing prime-field dictionary
modulo five. Rational inputs in the exhaustive shape oracle are small integers. Additional
nonintegral QQ fixtures use independent bounded integer-pair fraction arithmetic:
rank-five product/contraction raises a cubic index for dimensions 0–3, agrees
with mode_product, and remains invariant under a nonadjacent rank-five axis
permutation. Cubic pullback/evaluation checks dimensions zero and two, including
three successive zero-input-to-one-output mode products. Non-Eq function entries
also exercise generic construction, lookup, map and permutation.

Validation before the lookup investigation: nine test blocks pass on each of native, wasm-gc and JS with
`--deny-warn`; generated interfaces, format and the symbolic purity audit pass.
The separate `statgeometry` integration uses mode products for raised alpha
connection coefficients and cubic pullback, and tensor products plus repeated
contraction for scalar curvature. This package's frozen API remains independent
of that caller and of the Riemann raw component aliases.

This representation favors a small immutable invariant and reuse of existing
ADT arithmetic, not speed. Cardinalities and offsets use unary Nat; lookup in a
flat Chain is linear in the offset. Coordinates require rank-sized chains,
permutation rebuilds data, and contraction/mode products repeatedly look up
entries. Large dense tensors can therefore be expensive in time and allocation.
No storage compactness, tensor compiler, parallelism, numerical stability,
performance improvement, or arbitrary-dimension scalability is claimed.


A frozen pre-optimization lookup implementation is retained in white-box tests
for any subsequent traversal experiment. A recording semiring compares the full
sequence of plus/times operands, including zero coefficients, on all small
contractions and mode products. This protects callback counts and order in
addition to the independently checked shapes and values.
