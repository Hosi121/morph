# Fraction-free Bareiss determinant experiment

The isolated `src/bareiss` package implements an integer Bareiss determinant and a QQ wrapper which clears denominators with one positive LCM per row. It leaves `linear`, `rowreduce` and `berkowitz` unchanged. The correctness milestone passes **134 tests on native, JS and WasmGC**, including 132 independent determinant fixtures. Performance adoption remains a separate measured decision.

[Integer kernel](../../src/bareiss/bareiss.mbt), [rational wrapper](../../src/bareiss/rational.mbt), [generated API](../../src/bareiss/pkg.generated.mbti), [independent generator](../../tools/generate_bareiss.py), [paired benchmark cohorts](../../src/bareiss/cohort_bench_wbtest.mbt).

The trailing matrix recurrence is `(pivot*a_ij-a_ik*a_kj)/previousPivot`, starting with previous pivot one. [Bareiss, *Sylvester's Identity and Multistep Integer-Preserving Gaussian Elimination*, §I equations (6)–(8), §II.A.2 and the pivot discussion/Figure 3](https://www.ams.org/mcom/1968-22-103/S0025-5718-1968-0226829-0/S0025-5718-1968-0226829-0.pdf) derives integer preservation and the determinant identity, and discusses row interchange when a pivot vanishes. This implementation uses the one-step algorithm with immutable shrinking trailing matrices. Moving the first available nonzero pivot row to the front records the parity of every adjacent row interchange. A missing pivot makes the determinant zero; negative pivots are retained as signed previous divisors.

Every integer division uses magnitude quotient/remainder and explicitly requires remainder zero. `exact_divide` returns `ZeroDivisor` for divisor zero and `InexactDivision` for a nonzero remainder; there is no rounding. Tests exhaust signed numerators `-16..16` and divisors `-8..8`, and inject an invalid previous divisor into the internal recurrence to confirm an error is reported. Non-square matrices return `NotSquare`; the empty determinant is one. No kernel machine number, array, mutation, FFI or unwrap is used.

For QQ, each row is scaled by the LCM of its canonical positive denominators. All scale divisions are checked exactly. Integer Bareiss is then applied and the signed determinant is divided by the product of row scales, yielding a normalized exact Rational. This wrapper does not invoke field Gaussian elimination.

The independent oracle uses direct Fraction permutation expansion for sizes through five and a separate Fraction Gaussian implementation for six/eight. The two oracle methods agree on every small fixture. Cases include all 81 matrices of size two with entries in `{-1,0,1}`, random rational matrices through five, dense integer/rational six/eight, singular and first-column-zero eight, first/intermediate row pivots and a three-row cycle. Tests check both the new result and the frozen `@linear.determinant` against the independent answer; integer inputs also check `integer_determinant`.

All heavy work uses the shared CPU 10 lock. `.tools/bareiss-20261116/oracle.json` retains inputs and exact answers; `validation.json` and its logs retain commands, UTC completion, return status and nonzero test totals. `frozen-dependencies.json` records byte equality against `a8e7207` for `linear`, `rowreduce` and `berkowitz`. Formatting, API generation, warnings-as-errors, fixture drift and the symbolic-purity gate pass. These finite executable checks are not a formal proof of the compiler or exact-arithmetic implementation.

The eight prebuilt benchmark cohorts are small, integer six/eight, rational six/eight, singular eight, pivot eight and early-zero eight. Each cohort contains two or three matrices. Both algorithms are compiled into the same backend artifact; input construction is outside the timed closure. The candidate measurement includes QQ row-denominator conversion, even for integer-valued matrices, so it compares the practical rational APIs. No norm/resultant performance claim follows from these determinant cohorts. Existing public paths remain unchanged pending the recorded measurements.
