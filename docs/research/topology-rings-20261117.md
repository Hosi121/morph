# 積・相対群・崩壊を位相の共通部品から作る

[研究索引](README.md) / [使うための章](../handbook/cohomology-relative-collapse.md)

## 目的と区切り

同じ加法的ホモロジーを持つ空間を積で区別し、部分空間との関係と、位相を保つ簡約を実装する。
正本はmain、開始点は `8997862`。純ADT・厳密係数を維持し、三つの核とfiltered adapter、
独立照合、ツアー、文書、コミット・公開・作業場所の片付けを一区切りとした。

| 担当 | 独立する範囲 | 返す証拠 |
| --- | --- | --- |
| コホモロジー環 | `src/cohomology`、専用fixtureと研究記録 | 商の完全な基底、cochain代表、cup積、全次数の積表 |
| 相対群 | `src/chainhomology`、`src/relativehomology`、homologyの内部共通化 | 商の境界、整数cycle格子、連結写像、境界に関する下降 |
| 単体崩壊 | `src/collapse`、専用fixtureと研究記録 | 自由面、実際の除去先、整数I/P/H、収縮列 |
| root | `src/filteredcollapse`、ツアー、文書、統合検査 | gradeを保つ行列、元のバーコードとの比較、分野間の実行例 |

既存homologyの公開APIを固定し、内部を共通化する担当と、それを使う二担当を独立させた。
rootは合意したcollapseの型・関数にだけ依存する。
作業契約、DAG、実行記録は `.tools/topology-rings-20261117/task-*.json` に分けて保存した。
重いbuild・testは `tools/measure --cpu 4` の共有lockで直列化する。

## 実装で確かめる接続

トーラスと `S1 ∨ S1 ∨ S2` は整数H0/H1/H2がともにZ/Z²/Zで、GF(2)のBetti数も同じ。
cup積では、トーラスの独立な一次の類の積は非零、wedgeでは0になる。
RP2では二進の一次の生成元の平方が非零になる。
加法的な不変量から、具体的な代表と積の不変量へ進んだ。

整数の相対群は既存homologyと同じ行列対の核を使う。
円盤の相対面が境界円周の生成元へ移り、区間の相対辺が端点の差になることを確認する。
この接続では元と先のSmith座標の変換と、境界の代表の違いが0へ落ちる式が必要だった。

filtered崩壊は、通常の収縮が最終ホモロジーだけを保つことと、grade全体の持続性を保つことを分ける。
同gradeの組だけを除き、I/P/Hの各成分のgradeまで確認する。
正方形のRipsでは15→11単体になっても、正の長さの区間と無限区間の多重集合が一致する。
比較では単体番号を無視する。単体を除くと番号は変わり、同grade内のpairingも一意ではない。

## 根拠と限界

- [コホモロジー環の記録](cohomology-20261117.md)：完全な商基底、積表、独立set-span参照。
- [相対群と連結写像の記録](relativehomology-20261117.md)：整数の代表と下降、315小対、RP2のねじれ。
- [単体崩壊の記録](collapse-20261117.md)：167複体、9,781候補、340収縮と独立な行列検査。
- [Mischaikow–Nanda](https://people.maths.ox.ac.uk/nanda/source/DMPers-Final.pdf)：filtered chain equivalenceと持続性の保存。今回の限定的な自由面除去を、論文の一般アルゴリズムと同一視しない。

filtered adapterでは、空・一点・単体・閉曲面・尾付き円周、三つのgrade規則、正方形のRipsを検査する。
異なるgradeを持つ自由面を消すと、実際にH1の `[1,2)` を失う反例も含める。
証拠の元・先・手順を改変した場合と、行列が未来のgradeへ写す場合は拒否する。
単体数の削減は確認するが、実時間の高速化は同条件の比較なしには主張しない。
