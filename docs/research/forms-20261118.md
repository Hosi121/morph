# Polynomial differential forms on rational affine space

## Frozen API and conventions

This package models the exterior algebra of QQ-polynomial differential forms on
one affine coordinate space. A Form has a variable count n and a fixed exterior
degree k; its coefficient polynomials may have mixed ordinary polynomial degrees.
It does not model arbitrary manifolds or compute their de Rham cohomology.

The opaque checked `Form` has canonical sparse terms. Public input `Term` holds a
coefficient Polynomial and a Chain of differential indices. `form(n,k,terms)`
validates every coefficient dimension, every index-list length k and every index
range before any zero/repeated-index elimination. Arbitrary permutations are
sorted with their sign; repeated differentials vanish; equal bases combine.
Canonical basis indices increase strictly, and the term list is lexicographically
increasing. Zero retains n and k, including k>n, where every validated expression
is algebraically zero.

Core API: `form`, `zero`, `scalar`, `variables`, `degree`, `terms`, `is_zero`,
`add`, `negate`, `wedge`, `exterior_derivative`. Wedge requires the same variable
space and adds exterior degrees. Add requires both variable and exterior degrees
to match, including zero operands. All producers use exact rational operations.

The second milestone adds opaque checked `VectorField` with n polynomial
components in n variables, `contract(X,omega)` and `lie_derivative(X,omega)`.
Contraction returns Result[Form?,FormError]: degree zero returns None, representing
the zero in the unmodelled degree -1 space. Compatibility is checked before this
zero case. Lie derivative uses Cartan's formula and preserves omega's degree.

The third milestone adds opaque `PolynomialMap` from a source affine
space to the target with one source-variable polynomial per target coordinate.
Target dimension is the coordinate-list length. `pullback(map,omega)` returns a
form on the source. Empty target coordinates and zero-variable spaces are valid.

`radial_homotopy` also returns Result[Form?,FormError], with None at degree zero.
For a coefficient monomial of total degree r and exterior degree k>0 it applies
`(r+k)^(-1) i_E`, where E is the Euler vector field. Thus mixed degrees are handled
term by term. `primitive` accepts only closed forms of positive exterior degree
and returns a checked radial primitive. In degree zero the identity is
`H(df)=f-f(0)`; no primitive for a nonzero constant is promised.

These sign, grading and homotopy conventions follow the author's
[Meinrenken lecture notes](https://www.math.toronto.edu/mein/teaching/LectureNotes/Man.pdf),
Cartan calculus and Theorem 4.25/Corollary 4.26/Exercise 4.28. The implementation
will remain pure ADT recursion and reuse the existing opaque polynomial package.
Independent Python Fraction sparse-dictionary/permutation-sign fixtures and
algebraic identities will check results. Shared coefficient arithmetic is not a
whole-program independent oracle.

## Milestone 1: canonical exterior algebra and derivative

The checked constructor, zero/scalar forms, getters, add/negate, wedge and exterior
derivative are implemented. Validation is a separate first pass over every raw
term; antisymmetrization or a zero coefficient cannot bypass it. Basis ordering
uses pure insertion sorting with sign accumulation and repeated-index detection.
Coefficient combinations use the unchanged canonical polynomial operations.

`tools/generate_forms_fixtures.py --check` regenerates the entire test corpus using
Python Fraction sparse dictionaries and inversion-count signs, separately from
the production chain/insertion algorithm. Expected canonical Terms bypass the
Form constructor under test. The corpus has 200 complete normalization/derivative
examples and 64 complete wedges, together with d-squared-zero, graded Leibniz and
skewcommutativity checks. Malformed input, cancellation, zero-variable and k>n
cases are explicit tests.

Milestone 1 passes **266 tests on each of native, JS and wasm-gc with deny-warn**.
Generated public interface, fixture regeneration and the full repository purity
gate also pass. The approved scope is new forms files, one dedicated fixture
generator and this report; Markov and all shared packages/indexes/tools/check
remain unchanged. No performance claim is made.

## Milestone 2: contraction and Cartan Lie derivative

VectorField validation checks exactly n components and each polynomial dimension,
even for zero components. `contract` checks space compatibility before handling
degree zero as None, and otherwise lowers degree by one with the standard
alternating omission signs. Higher-degree zero spaces and zero variables retain
their grading. `lie_derivative` implements Cartan's formula, treating the absent
degree -1 term explicitly so its result always has the original degree.

The generator adds 60 complete contraction and Lie examples. Its Lie oracle uses
the direct coordinate rule on coefficient functions and each differential basis
slot, rather than the production d/interior composition. Checks include
contraction-squared zero, commutation of Lie derivative with d, nonconstant vector
fields and functions. Expected canonical Terms again bypass Form normalization.
These independent host values supplement identities between shared operations;
coefficient Polynomial and exact ADTs remain shared implementation dependencies.

Milestone 2 passes **328 tests on each of native, JS and wasm-gc with deny-warn**,
generated interface, generator --check, and the full purity gate. Markov and all
existing shared package sources remain unchanged.

## Milestone 3: polynomial pullback, radial homotopy and primitives

PolynomialMap checks every coordinate's source dimension. Pullback first checks
the target form dimension, even for zero forms, substitutes coefficient
polynomials and wedges coordinate differentials. Zero source/target dimensions
are supported with their declared exterior grade. Exponentiation for symbolic
substitution halves the existing Nat exponent directly; it does not perform a
Nat-to-Binary-to-Nat round trip.

Radial homotopy splits every coefficient polynomial into monomials. On a
monomial of degree r in exterior degree k>0, pulling back by F(t,x)=tx gives a
dt coefficient proportional to t^(r+k-1) i_E. Integrating the t power gives the
exact factor 1/(r+k). The implementation applies this factor before summing mixed
degrees. At k=0 it returns None without division; `H(df)=f-f(0)` is checked
separately. Higher-degree zero spaces also retain their grading.

`primitive` checks positive degree and closedness, computes the radial candidate,
then calls `check_primitive`. This checker verifies both coordinate/exterior
gradings and the original d(candidate)=source equation without invoking radial
homotopy. It shares exterior differentiation and Polynomial/exact arithmetic;
that dependency is not claimed to be a whole-program independent certificate.
Nonclosed input and degree-zero input have explicit distinct errors.

The independent pullback oracle expands Jacobian minors with permutation
determinants, rather than invoking production wedge. The homotopy oracle embeds
the map (t,x)->tx, uses that determinant pullback, selects dt terms, and integrates
the resulting polynomial in t. It never uses the production Euler denominator
formula. The additional corpus has 112 full pullbacks with d-commutation and 90
full homotopies with dH+Hd=Id-eval0, closed/nonclosed primitive checks, varied
monomials and mixed polynomial degrees. Explicit examples cover nonconstant map
composition, points/empty targets, a mixed-degree volume form, wrong primitive
gradings and rejection of a nonclosed one-form.
