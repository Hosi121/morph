# Polynomial differential forms on rational affine space

## Frozen API and conventions

This package models the exterior algebra of QQ-polynomial differential forms on
one affine coordinate space. A Form has a variable count n and a fixed exterior
degree k; its coefficient polynomials may have mixed ordinary polynomial degrees.
It does not model arbitrary manifolds or compute their de Rham cohomology.

The opaque checked `Form` has canonical sparse terms. Public input `Term` holds a
coefficient Polynomial and a Chain of differential indices. `form(n,k,terms)`
validates every coefficient dimension, every index-list length k and every index
range before any zero/repeated-index elimination. Arbitrary permutations are
sorted with their sign; repeated differentials vanish; equal bases combine.
Canonical basis indices increase strictly, and the term list is lexicographically
increasing. Zero retains n and k, including k>n, where every validated expression
is algebraically zero.

Core API: `form`, `zero`, `scalar`, `variables`, `degree`, `terms`, `is_zero`,
`add`, `negate`, `wedge`, `exterior_derivative`. Wedge requires the same variable
space and adds exterior degrees. Add requires both variable and exterior degrees
to match, including zero operands. All producers use exact rational operations.

The next milestone adds opaque checked `VectorField` with n polynomial
components in n variables, `contract(X,omega)` and `lie_derivative(X,omega)`.
Contraction returns Result[Form?,FormError]: degree zero returns None, representing
the zero in the unmodelled degree -1 space. Compatibility is checked before this
zero case. Lie derivative uses Cartan's formula and preserves omega's degree.

The final bounded milestone adds opaque `PolynomialMap` from a source affine
space to the target with one source-variable polynomial per target coordinate.
Target dimension is the coordinate-list length. `pullback(map,omega)` returns a
form on the source. Empty target coordinates and zero-variable spaces are valid.

`radial_homotopy` also returns Result[Form?,FormError], with None at degree zero.
For a coefficient monomial of total degree r and exterior degree k>0 it applies
`(r+k)^(-1) i_E`, where E is the Euler vector field. Thus mixed degrees are handled
term by term. `primitive` accepts only closed forms of positive exterior degree
and returns a checked radial primitive. In degree zero the identity is
`H(df)=f-f(0)`; no primitive for a nonzero constant is promised.

These sign, grading and homotopy conventions follow the author's
[Meinrenken lecture notes](https://www.math.toronto.edu/mein/teaching/LectureNotes/Man.pdf),
Cartan calculus and Theorem 4.25/Corollary 4.26/Exercise 4.28. The implementation
will remain pure ADT recursion and reuse the existing opaque polynomial package.
Independent Python Fraction sparse-dictionary/permutation-sign fixtures and
algebraic identities will check results. Shared coefficient arithmetic is not a
whole-program independent oracle.

No implementation or validation result is claimed by this API-freeze milestone.
The approved scope is new forms files, one dedicated fixture generator and this
report; Markov and all shared packages/indexes/tools/check remain unchanged.
