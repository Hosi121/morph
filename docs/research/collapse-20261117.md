# Exact elementary simplicial contractions

This milestone asks whether finite simplicial simplification can return explicit
integer chain equivalences whose acceptance does not depend on trusting the
simplifier. `src/collapse` implements elementary free-face deletion and a checked
sequence of such deletions. The same integral homology, including torsion, is
retained in the finite examples below. Production uses immutable `Chain`, unary
`Nat`, `Bool`, exact integers, and recursion. Machine arithmetic and mutable
arrays occur only in tests and the independent Python oracle.

This is an executable certificate checker with finite validation. It is not a
universal formal proof, a general discrete Morse implementation, a decision
procedure for contractibility, an optimal simplifier, or a performance claim.

## Elementary pair and actual target

`Pair { lower: sigma, upper: tau }` must name nonempty canonical simplices already
in the actual source `K`. Increasing vertex order supplies their orientations,
as in `homology`. `sigma` must be a codimension-one face of `tau`. Deleting
exactly these two simplices must produce a valid complex `L`.

This last condition directly checks the free-face property. If a retained
simplex had `sigma` as a face, its required face would be missing. If `tau` had
a larger coface, that coface would remain with a missing face. Thus valid exact
deletion implies that `tau` is maximal and is the only strict coface of `sigma`.
The checker checks this supplied pair; it does not run the simplifier's free-pair
enumeration or choose another pair. `is_free(K,pair)` exposes the structural
check without building matrices.

[Forman, *A User's Guide to Discrete Morse Theory*, SLC 48 (2002), B48c,
§2, pp. 11–12](https://www.mat.univie.ac.at/~slc/wpapers/s48forman.pdf)
describes deleting a simplex together with a free face as a simplicial collapse
and a deformation retract. The present implementation restricts each step to a
codimension-one pair. It does not implement general acyclic matchings or the
Morse boundary construction from §7 of that paper.

## Integral contraction and matrix conventions

All chains are unreduced, so `d_0` has zero rows and one column per vertex.
Basis order in each degree is exactly `homology.simplices`, in lexicographic
order. Matrices act on column vectors. Let

\[
\epsilon=[\sigma:\partial\tau]\in\{1,-1\},\qquad
H(\sigma)=\epsilon\tau,\qquad H(x)=0\quad(x\ne\sigma).
\]

Inclusion `I` is the inclusion of retained basis simplices. Define
`Q=id-dH-Hd`. On `sigma`, `Q(sigma)=sigma-epsilon*d(tau)`, which has no `sigma`
coordinate. On `tau`, `Q(tau)=tau-epsilon^2*tau=0`. On all other basis simplices
`Q` is the identity, because no other simplex has `sigma` as a codimension-one
face. Consequently `Q` has no deleted coordinates and defines a projection
`P: C(K)->C(L)` after removing those coordinates. The producer builds this
projection directly; independent tests instead compute the full matrix
`id-dH-Hd` and then restrict its rows.

Every certificate contains the source, target, pair, orientation, and a list of
`DegreeMaps { inclusion, projection, homotopy }`. For each degree `k`, these
maps have shapes

| Map | Rows | Columns |
| --- | --- | --- |
| `I_k` | number of source k-simplices | number of target k-simplices |
| `P_k` | number of target k-simplices | number of source k-simplices |
| `H_k` | number of source (k+1)-simplices | number of source k-simplices |

`check(K,actual_target,witness)` binds both endpoints and the actual exact
deletion, recomputes the oriented incidence, requires canonical inclusion and
homotopy entries, and checks the following integer identities, with matrix
dimensions checked independently:

\[
d_LP=Pd_K,\quad d_KI=Id_L,\quad PI=\operatorname{id},\quad
\operatorname{id}-IP=d_KH+Hd_K.
\]

These identities give inverse homology maps over `Z`, since a chain homotopy
does not change the induced map on homology. No homology or Smith computation
is needed to accept an elementary certificate.

The stored list has exactly one entry for every degree `0` through `n`, where
`n` is the maximum cardinality of a source simplex. The top dimension is
`n-1`; degree `n` therefore checks the first zero chain group, including its
boundary's nonzero number of rows and zero columns. All later groups and maps
are uniquely zero. In degree zero the preceding homotopy is the source-vertices
by zero matrix. This handles the unreduced `H_0` identity explicitly rather
than silently augmenting the complex. `degree_maps` returns `None` outside the
stored range, not a matrix with guessed dimensions.

All certificate fields are public to permit independent producers and hostile
mutation tests. Consumers must call `check` with the actual source and actual
returned target. Reading `witness.target` alone is not acceptance.

## Resumable search and sequence trust boundary

`start(K)` creates an immutable `Search`. `run(search,fuel)` scans all ordered
pairs `(lower,upper)` in the current complex's lexicographic simplex order.
Each fuel unit attempts exactly one candidate pair, including rejected pairs.
After a successful checked collapse, scanning restarts on the new complex.
Exhausting a row of candidates and advancing to the next lower simplex does
not consume fuel. No collapse or pending candidate is lost on `Paused`.

Fuel bounds candidate attempts. Matrix construction, certificate checking,
structural validation, and immutable list traversal within an attempt are not
separately metered. It is not a time, recursion-depth, or allocation bound.

`sequence(search)` exposes a chronological checked prefix. `Stalled(sequence)`
means this run exhausted every ordered pair in its final complex. It means
irreducible by elementary free-pair deletions in this state, not that the
original complex is noncollapsible, that alternative prior choices cannot
simplify further, or that a complex is noncontractible. The search neither
backtracks nor permits expansions.

`check_sequence(K,actual_target,sequence)` checks actual endpoint binding and
every chronological local certificate, including that each step's source is
the previous step's target. It validates the contraction path, not the claim
that no further free pair exists. `Stalled` is the status returned by the
trusted exhaustive producer; wrapping an arbitrary public sequence in that
enum constructor does not supply an independent irreducibility proof. The
tests independently enumerate every final pair to verify this status. A single
cumulative matrix contraction is not materialized; the checked local path is
the public witness.

## Finite evidence

| Example | Source simplices | Result simplices | Result |
| --- | ---: | ---: | --- |
| Filled triangle | 7 | 1 | vertex |
| Filled tetrahedron | 15 | 1 | vertex |
| Square triangulated by one diagonal | 11 | 1 | vertex |
| Circle | 6 | 6 | no free pair |
| Tetrahedral sphere | 14 | 14 | no free pair |
| Six-vertex projective plane | 31 | 31 | no free pair |
| Circle with two dangling edges | 10 | 6 | original circle |
| Projective plane with two dangling edges | 35 | 31 | original projective plane |

The existing integer homology engine checks source/result groups in degrees
zero through four for these examples, also empty and singleton complexes.
The projective-plane tree example makes genuine deletions while preserving its
`H_1=Z/2` torsion. Nonfree faces, wrong codimension, missing/noncanonical faces,
changed orientation, source, actual target, witness target, map list length,
matrix dimensions, homotopy sign, and reversed step order are rejected.
Every stored matrix entry of the tetrahedral contraction is separately changed
by `+1` without changing its shape; every such certificate is rejected.

`tools/generate_collapse_fixtures.py` independently enumerates all **167**
complexes supported on subsets of four labelled vertices. Set containment,
not closure after deletion, classifies all **9,781** ordered candidate pairs;
exactly **340** are elementary pairs. Python builds numeric integer boundaries
and contractions and checks all four identities for every accepted pair.
Generated fixtures drive a second machine-array implementation in MoonBit
tests: it reconstructs oriented boundaries by vertex deletion, compares every
entry of `I`, `P`, and `H`, and checks all identities and zero shapes. Every
candidate's acceptance agrees with independent enumeration, and every final
search target has no free pair. These checks go beyond Euler characteristic or
field-rank equality. They remain finite tests, not a proof for arbitrary size.

Validation commands, serialized under the shared CPU-4 measurement lock:

```sh
tools/measure --cpu 4 python3 tools/generate_collapse_fixtures.py --check
tools/measure --cpu 4 tools/moon test src/collapse --target native -j 1
tools/measure --cpu 4 tools/moon test src/collapse --target js -j 1
tools/measure --cpu 4 tools/moon test src/collapse --target wasm-gc -j 1
tools/measure --cpu 4 tools/moon info src/collapse
python3 tools/audit_purity.py
```

The fixture generator uses the existing frozen `moonfmt` executable to produce
canonical test source. No external numeric package or floating point is used.
Filtered collapse is deliberately outside this package: a wrapper must enforce
filtration-grade compatibility before treating these maps as filtered maps.
