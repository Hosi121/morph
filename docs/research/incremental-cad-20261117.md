# 必要なセルから探索するCAD

[研究記録](README.md) / [厳密代数の計算経路](../handbook/algebraic-solving.md)

非線形実数SMTで、最初の厳密モデルが見つかった時点でSATを返し、
親セル上で真偽が確定した残り座標の展開を省く。
完全CADの入口を比較用に保ち、同じ式と射影階層に対して判断と証拠検査を比較した。

## 省略できる範囲を決める

親セルの座標をu、未選択の座標をvとして、元の各多項式を
`p(u,v) = Σ a_μ(u) v^μ` と係数ごとに分ける。
[prefixlogic](../../src/prefixlogic)は、この恒等式を有理係数の項から構成する。
係数多項式を親セルの射影族へ厳密に対応付け、族にない係数は未確定に保つ。
非定数のv項の係数が全て親セル上で零なら、pの符号は定数項だけから決まる。
その結果を六つの関係とBoolean結合へ伝える。

たとえば `x = 0 ∧ xy = 1` では、x=0のセル上でxy−1は常に−1となる。
x≠0のセルでは最初の等式が既に偽なので、どちらもy方向の根隔離を省ける。
「代表点で式が偽」というだけでは省略を認めない。

CADの状態機械は、親セルで検査した射影族の符号を子へ渡す。
偽の円柱は短い `Leaf(false)` で閉じ、真の円柱は未選択座標を厳密な零で補って
原式を検査したモデルを返す。SATでは残りの兄弟セルを構築しない。
UNSATでは全ての残存領域を閉じた木が必要になる。

## 短い証拠を検査する

証拠の公開構造は維持した。CAD checkerは元の式・atom列・全Collins射影を再検査し、
係数の分解計画も元の式と射影族から再構築する。
各親セルの根被覆・代表点・符号を検査した後でのみ、短い葉の一様な真偽を認める。
別の式の計画、係数の順序や親の符号の差替え、未知の円柱の偽への置換、
兄弟セルの欠落を受理しない。

[signcad](../../src/signcad)では、短い葉を残りの非空な実数座標全体の定数関数として畳み込む。
この有限な木の変換だけで幾何学的な正しさが得られるわけではない。
CAD checkerが保証する一様性と被覆を前提に、量化交代と自由変数の式化を維持する。
真の円柱からの証人も、同じ代数的係数体で残りの座標を補う。

## Boolean再帰の形式検査

[Leanモデル](../../formal/PrefixLogic.lean)は、原子観測が領域全体で健全という仮定の下で、
任意の深さの式が `Known(b)` を返すなら領域の全ての点で値がbになることを構造帰納法で示す。
係数の消滅やCAD被覆をこの仮定から勝手に導かない。
[実装との対応と未証明部分](../../formal/REVIEW-prefixlogic.md)を分けて記録した。
不正なAND・OR規則に変えた二つのモデルは、健全性補題の検査に失敗する。

## 入口と比較

| 目的 | 入口 |
| --- | --- |
| 従来の完全な分割と量化消去 | `cad.start / step / run` |
| SAT早期終了・偽の円柱の省略 | `cad.start_search / search_step / search_run` |
| 通常の非線形SMT | `realnlsmt.start` |
| 完全CADを使うSMTの比較用経路 | `realnlsmt.start_full` |

モデル・理論補題・最終RUP反証の公開構造は保った。
理論節はBoolean候補間で保持する。理論衝突後のCDCL再始動と、全Collins射影は両方式で共通である。
燃料切れや計算エラーは未完了またはエラーを返し、UNSATへ置き換えない。

同じrelease実行ファイルを使い、full→pruned→pruned→fullの順に比較する。
計測器は入力の構成後に時計を開始し、準備・探索・最終結果の外部検査を含める。
SMTの探索時間には通常経路の内部のモデル・理論補題・反証検査も含む。
射影の費用を別の実装へ移した比較ではない。
両方式は新しい係数計画の準備と検査も共通に行うため、この比は同一artifactの探索方式の比較であり、
過去のGit snapshotそのものとの速度比ではない。各起動は独立プロセスで、VMの定常状態だけを測った値ではない。

```sh
tools/measure --cpu 4 tools/moon build src/cmd/incrementalbench --target native --release
tools/measure --cpu 4 python3 tools/compare_incremental_cad.py \
  --artifact _build/native/release/build/cmd/incrementalbench/incrementalbench.exe \
  --output .tools/incremental-comparison.json
```

## 検査と計測の結果

係数判定は、全六関係の7,290有理点照合と162件の一様性確定、3変数の係数合成、
非整数の消滅点、不足した係数と不正なplanを検査した。
符号木は、短縮した全512個の2D真理値表と3D例について20,886回の真偽比較、3,749回の証拠検査を行った。
独立レビューの16入力では、Z3・完全CAD・枝刈り探索が全3 backendで一致した。
既存のSMT用Z3参照41入力も通常の新しい探索経路で通過している。

以下はSMTの準備・探索・最終検査を含む全体時間。CPU 4へ固定し、共通lockで直列化した。
各方式2回の中央値であり、一般的なsolver benchmarkや統計的な信頼区間を示すものではない。
入力は枝刈りが効く状況と、効かない一変数の対照を含む8例である。

| 入力 | native full→pruned | native比 | JS比 | WasmGC比 |
| --- | ---: | ---: | ---: | ---: |
| x=0 ∧ xy=1 | 1.398→0.602 ms | 2.32× | 1.57× | 2.09× |
| 円周上のSAT | 1.889→0.709 ms | 2.67× | 1.68× | 1.13× |
| 3変数の従属SAT | 222.640→3.410 ms | 65.29× | 7.95× | 6.30× |
| 3変数の従属UNSAT | 1284.165→37.309 ms | 34.42× | 7.65× | 3.79× |
| 4変数の従属UNSAT | 12355.386→94.627 ms | 130.57× | 34.12× | 21.41× |
| 一変数UNSATの対照 | 1.122→0.951 ms | 1.18× | 1.12× | 1.00× |

3変数SATは `x²=2 ∧ y=x ∧ z=y ∧ z²=2`。
同じ式の最後を `z²≠2` にすると3変数UNSATになる。
4変数UNSATは `x=y ∧ y=z ∧ z=w ∧ x²=2 ∧ w²≠2`。
4変数例のSMT遷移数は20,244から228へ減った。

一変数UNSATは遷移数が変わらず、CADだけを測るとnativeで約5.5%、JSで約3.8%、WasmGCで約1.5%遅い中央値だった。
SMTを含めた比も揺れるため、この対照での改善は主張しない。
`start_full`を残し、全入力で速くなるという採用理由にはしていない。

全192回の計測は完了し、全ての結果を元の式・証拠へ照合した。

## 今回の境界

局所射影や、理論衝突後のCDCLのtrail・内部学習状態の再利用は次の段階である。
係数が消えると分かった場合だけを省略するため、`y²+1` のような正値性の一般的な推論は行わない。
全射影が大きい入力では、探索を減らしても準備費用が支配的になり得る。
既存の密な高深度の体演算の負荷も残る。
独立レビューで保存した二次式の追加stress例は、準備が完了した後も8秒の探索診断で未完了だった。
この例を成功や射影だけの問題とは扱わず、厳密な入力と打切り条件を参照記録へ残す。
