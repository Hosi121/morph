# 全自己同型から固定体へ

[ドキュメント](../README.md) / [研究記録](README.md) / [利用ガイド](../handbook/galois-fixed-fields.md)

K(i) の基底演算を、体の対称性と中間体の計算へつなぐ。
今回の問いは、全根が一つの体に入るという検査可能な条件の下で、
自己同型とその固定体を、既存の厳密算術・線形代数から構成できるかである。

## 根の探索と対称性の列挙を分ける

`complexautomorphism` は `L=QQ(α,i)` と、α の最小多項式の全根を受け取る。
入力する根は既に同じ L の元である必要があり、分解体探索はこの段階に持ち込まない。
根の個数、相異性、同じ体への所属、元の最小多項式での零評価を検査する。
実埋込みを持つ K=QQ(α) では i∉K なので、α の像と i の二つの符号から、
全 `[L:QQ]` 個の自己同型が得られる。

これは汎用的な条件付き構成であり、D4 の合成表だけを埋め込んだ実装ではない。
元の剰余多項式を生成元の像へ実際に代入して、任意の元への作用を計算する。
全合成も生成元の像から計算し、元の候補一覧へ戻す。
表が抽象的な群になることだけでは、この体の自己同型の証拠として不十分である。

公開証拠は体、根の順番、両生成元の像、合成表、単位元・複素共役の番号、全逆元を持つ。
検査器は元の体に束縛してこれらを再計算し、返した private Group の実体も検査する。
入力する根を並べ替えれば、同じ群の番号は変わる。
独立参照には単位元が先頭でない例も入れた。

`QQ(√2,i)` の全自己同型群は V4 だが、`t²−2` の最小分解体は `QQ(√2)` である。
計算する体の群と、多項式の最小分解体の群を混同しない。
`α=⁴√2` では `±α,±iα` が全根であり、`i=(iα)/α` を根から回復できる。
従ってこの例の L は最小分解体そのもので、その群は位数8の D4 である。

## 固定される空間全体を計算する

`fixedfield` は検査済みの群と、その番号の集合 H を受け取る。
番号の順序と重複を整理し、単位元、両側逆元、合成について閉じることを検査する。
閉じない集合を渡したときに、勝手に生成部分群へ広げることはしない。

元の L の基底に作用する行列 Mσ を作り、`Mσ−I` を縦に積む。
その同次線形系を既存の `linear.solve` に渡すと、固定される空間の基底を得る。
生産側の nullspace 出力をそのまま証拠とはせず、検査器は次を確認する。

- 各作用行列が、元の群による基底への実際の代入と一致する。
- 制約行列がこれらの作用から組み立てられている。
- 返す全基底が同じ体に属し、H の全作用で固定される。
- 基底が有理線形独立で、制約行列の rank と基底数の合計が元の次数に一致する。
- 固定体の次数と H の位数の積が元の次数に一致する。

固定される独立な元を少数見つけただけでは、固定体全体を計算したとは言えない。
rank と nullity の検査を加え、抜けのない有理基底であることを検査する。
同じ空間を張る別の基底も `from_certificate` で受け取れるが、
`check_result` では呼び出し元へ実際に返した基底そのものと証拠を照合する。

`contains` は各自己同型への代入で所属を判定する。
`coordinates` は固定体の基底に対する一意な座標を解き、`from_coordinates` は線形結合で元へ戻す。
異なる context、固定されない元、誤った次元を区別する。

## 基礎部品の整理

複素数体、primitive 表示、自己同型で重複していた座標取り出しと Horner 評価を
`complexfield.coordinates`、`from_coordinates`、`evaluate_polynomial` へまとめた。
固定体の作用行列・座標変換もこの入口を使う。
不変な自己同型の一覧は、一回の所属判定や作用行列の作成中で共有する。
これらは共通の実装と不変条件を保つ整理であり、実測していない速度向上は主張しない。

## 有限例と独立参照

[群の独立参照](complexautomorphism-oracle-20261117.md)は、整数の組 `(k,s)` による
独立な有限群モデル、Fraction の剰余算術、SymPy の厳密代入を使う。
C2、V4、D4 と D4 の根順序変更について、合成・逆元・根への作用・元への作用を照合する。
公開証拠に対しては、正しい別の抽象群表、根・像・番号・source・返却物の差し替えも検査する。

[固定体の独立参照](fixedfield-oracle-20261117.md)は、有限群の部分群を外部で全列挙し、
独立な作用行列と SymPy の有理 nullspace を計算する。
元の空間の既知の固定ベクトル、所属、次数、生成元の最小多項式と照合する。
ライブラリは指定された H の固定体を求め、部分群自体の全列挙は独立参照側で行う。
`z⁴−2` の全10中間体は[利用ガイドの表](../handbook/galois-fixed-fields.md#quartic-fields)にまとめた。

これらは有限例と実行時の証拠検査であり、Galois理論、コンパイラ、共有算術全体の形式証明ではない。
群・行列は有限だが、有理係数のビット長と実行時間・メモリの上限は固定していない。
この段階の性能の比較計測はしていない。
任意の複素数体の合成、一般多項式の分解体探索、群の一般分類、固定体の自動一生成元化は次の課題に残る。
