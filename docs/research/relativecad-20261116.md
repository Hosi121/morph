# 数体係数の一変数符号分割

[ドキュメント](../README.md) / [研究・探索記録](README.md)

[relativecad](../../src/relativecad) は、固定した実埋込みの Q(α) を係数体とする
一変数多項式の等式・不等式と Boolean 結合を判定する。
四乗根2のように係数体を越える根も、一根区間と相対多項式で表せる。
Q(α,β) の体を新しく構築する処理ではない。

## 表現と手順

入力の全係数は同じ検査済み Field に属する必要がある。
別の共役・別の根区間を持つ Field は混ぜず、実際には使わない Boolean 分岐にもこの検査を行う。
非零の atom の積を作り、orderedsturm で平方因子を除去して全実根を隔離する。
零の atom は積から除き、符号0として保持する。

積の一根区間に atom の根が一つあれば、その根での符号は0。
根がなければ区間中点で評価した係数体の符号を使う。
atom の全根が積の根に含まれることと、積の一根性がこの分類の前提である。
端点は全て半開 `(a,b]`。隣接する隔離区間に厳密な隙間ができるまで右側を精細化し、
根の点と各開区間の有理標本から全セルを作る。

checker は、指定 Problem の積と isolation 証拠を結び付け、全根被覆を確認する。
さらに隔離区間から正規の標本列を再構成し、各 atom の符号と式の真偽を照合する。
checker 自身も orderedsturm と係数体算術を信頼する。
この層の全称的な形式証明は行っていない。

## 再開と境界

Machine は根の隔離、区間の分離、セルの分類の三段階を保持する。
燃料0は Paused、続きは複製して再実行できる。
一歩の中に係数体の除算、符号証拠の作成・検査などが入るため、燃料は実時間上限ではない。
AlgebraicPoint は所有する Problem の積多項式と Field があって初めて値を指定する。

最初の手書き検査は、正負の √2 埋込み、`y²−√2` と `y−1` の符号分割、
全称式、零・定数、反復因子、端点、再開と続きの再利用を含む。
根の欠落、符号・真偽の改変、別 Field の証拠も拒否する。
独立な期待値による追加レビューは別の記録に残す。
