# 複素数体の対称性と固定体

[ハンドブック](../../HANDBOOK.md) / [複素数体と一生成元](complex-fields.md)

同じ体に入る全共役を指定すると、元を入れ替える自己同型を計算できる。
さらにその部分群から、すべての作用で動かない元の体を求められる。
この段階では、体の演算だけでなく、対称性と中間体の関係も厳密に扱う。

## 全根が入る体から自己同型を作る

入力は検査済みの `L=K(i)`、`K=QQ(α)` と、α の最小多項式 `p` の全根である。
根はすべて同じ `complexfield.Field` の元で指定する。
`complexautomorphism.prepare` は、根がちょうど `degree(p)` 個あり、重複せず、`p` を零にすることを確認する。

各根 β と `i` の符号から、二つの生成元の像を選ぶ。

\[
\sigma(\alpha)=\beta,\qquad \sigma(i)=\pm i.
\]

`K` は実埋込みを持つため `i∉K`。この選択は `[L:QQ]=2 degree(p)` 個の異なる自己同型を与える。
`apply` は `a(α)+i b(α)` を `a(β)+σ(i)b(β)` へ写す。
`compose(group,left,right)` は **right を適用した後に left** を適用する。
合成表の行が left、列が right であり、表は実際の生成元への代入から作る。
根の入力順が変われば番号も変わるため、単位元が先頭であるとは仮定しない。

`check_result(source,group,proof)` は元の体、全根、生成元の像、各合成、
単位元、複素共役、両側逆元と実際に返した group を検査する。
抽象的な群の公理を満たす表でも、この体の代入と一致しなければ受理しない。

これは **指定された体 `L` の `Gal(L/QQ)`** である。
たとえば `QQ(√2,i)` では位数4のV4を得るが、`t²−2` 自身のGalois群は位数2である。
指定した体が元の多項式の最小の分解体かどうかも区別する。
全根を探して適切な体へ自動で加える機能は、この入口には含まれない。

## 部分群から固定体を求める

`fixedfield.prepare(group,members)` は、自己同型の番号の集合 H を受け取る。
並び順と重複を正規化し、単位元、逆元、合成について閉じていることを確認する。
生成元の一覧から部分群を自動で生成する入口ではない。

元の有理基底を B とし、σ の作用を有理行列 `Mσ` で表すと、固定される座標 v は

\[
(M_\sigma-I)v=0\quad(\sigma\in H)
\]

を満たす。これらを積み重ねた線形方程式の核が、固定体 `L^H` の有理基底になる。
既存の有理行列と線形方程式を再利用し、浮動小数点の固有ベクトルは使わない。

`basis` と `degree` が固定体の基底と次数を返す。
`contains` は元を実際に各自己同型へ渡して固定されるか調べ、
`coordinates` と `from_coordinates` が固定体の基底での表示を往復する。
元の `complexfield` で乗算・逆元を計算し、固定体への所属と座標を確認して使える。

検査器は各作用行列を再計算し、各基底が固定されることと独立性を確認する。
さらに `rank(A)+degree(L^H)=degree(L)` によって固定される元の取りこぼしを排除し、
`degree(L^H)*|H|=degree(L)` も照合する。
固定される元をいくつか見つけるだけの計算とは、この完全性の検査が異なる。

## z⁴−2 の全中間体

α を正の実四乗根 `⁴√2` とする。`L=QQ(α,i)` は次数8で、`z⁴−2` の分解体である。
回転 r と複素共役 τ を

\[
r(\alpha)=i\alpha,\quad r(i)=i,\qquad
\tau(\alpha)=\alpha,\quad\tau(i)=-i
\]

と置くと、`r⁴=1`、`τ²=1`、`τrτ=r⁻¹` となり、群は位数8の二面体群 D4 である。
固定体を求めると、10個の部分群に対応して次の体を得る。

| 部分群 H | 固定体 L^H | QQ上の次数 |
| --- | --- | ---: |
| 単位元だけ | `QQ(α,i)` | 8 |
| `⟨r²⟩` | `QQ(√2,i)` | 4 |
| `⟨τ⟩` | `QQ(α)` | 4 |
| `⟨rτ⟩` | `QQ((1+i)α)` | 4 |
| `⟨r²τ⟩` | `QQ(iα)` | 4 |
| `⟨r³τ⟩` | `QQ((1−i)α)` | 4 |
| `⟨r⟩` | `QQ(i)` | 2 |
| `⟨r²,τ⟩` | `QQ(√2)` | 2 |
| `⟨r²,rτ⟩` | `QQ(i√2)` | 2 |
| 全体 D4 | `QQ` | 1 |

たとえば `(1+i)α` の最小多項式は `t⁴+8`。
実数の固定体だけでなく、非実の四次体も同じ線形代数で取り出せる。
この表の「固定体」は単一の `numberfield.Field` への再構成を意味せず、
元の複素数体内での完全な基底と座標を持つ `fixedfield.Field` である。

## 実装と検証の範囲

自己同型の列挙には、α の全根が指定した `K(i)` に既に入ることが必要である。
一般の複素拡大体の合成、任意多項式の分解体探索、resolventによる群分類、
任意の固定体の一生成元探索や整数基底計算は別の課題として残る。

公開証拠は入力・context・実際の返却値にも結び付けて検査する。
独立した有限群モデルと厳密線形代数による例の照合は、一般の体論やプログラム全体の形式証明とは区別する。

[fixedfield](../../src/fixedfield/pkg.generated.mbti)、
