# 実数制約と量化消去

[ハンドブック](../../HANDBOOK.md) / [ドキュメント](../README.md)

有理係数多項式の等式・不等式を、浮動小数点へ丸めずに扱うための章である。
個々の実代数的数を計算すること、一階式の量化を消去すること、量化なしの制約から一つの解や反証を探すことでは、入口と出力が異なる。
演算で扱う無理数は、定義多項式と選択した根で表せる実代数的数である。
零次元の多項式系から全実点を求め、最小多項式や数体へつなぐ経路は[厳密代数の計算経路](algebraic-solving.md)を参照。

`tools/moon run src/cmd/realclosed` で量化交代、二自由変数への射影、三段平方根、非線形SMTの小例を実行できる
（[出力](../REALCLOSED_TOUR.txt)・[ソース](../../src/cmd/realclosed/main.mbt)）。

## 入出力から入口を選ぶ

| したいこと | 入力 | 主な入口と出力 |
| --- | --- | --- |
| 選んだ実根を厳密に計算する | 有理多項式と一根区間 | [realalgebraic](../../src/realalgebraic)の `Number`。比較・四則演算 |
| 同じ数体で演算を繰り返す | 検査済み最小多項式と選択実根 | [numberfield](../../src/numberfield)の `Field` と `Element`。別の数体との合成は `compositum` で明示する |
| 多段の選択実根を係数に使う | 親の順序体上の多項式と一根区間 | [realtower](../../src/realtower)の `Field` と `Scalar`。CADの座標もこの表現を使う |
| 一変数制約の解領域を見る | `realcad.Formula` | [realcad](../../src/realcad)の符号不変セル、証人、全称式の反例 |
| 二変数式のyを量化し、xの領域を得る | 二変数の式と存在・全称の選択 | [cad2](../../src/cad2)の分解から `semialgebraic.from_cad2` で代数的端点の区間集合 |
| 一階実数式の量化を消去する | 自由変数数と `realformula.Formula` | [realclosed](../../src/realclosed)の量化なしの有理多項式式。閉じた文では真偽も取り出せる |
| 量化なしの非線形制約を判定する | 変数数と `realcad.Formula` | [realnlsmt](../../src/realnlsmt)の厳密モデル、検査可能な反証、または再開状態 |

`cad` は任意変数の円柱代数分解（CAD）を直接扱う下位の入口であり、`realclosed` と `realnlsmt` が利用する。
CADは、各多項式の符号が一定になるセルへ実数空間を分け、変数を一つずつ積み上げる構造を保つ。
APIの正確な型は各パッケージの `pkg.generated.mbti` が正本である。

## 実数の表現と不変条件

厳密な数の表現では、定義多項式だけでは共役のどの根を使うか決まらない。
`realalgebraic.Number` は非零の有理多項式と、その実根がちょうど一つ入る半開区間 `(a,b]` を持つ。
`numberfield` は選択した実埋込みのもとで `h(t) mod m(t)` を使い、次数を最小多項式mの次数未満に保つ。
最小多項式への正規化、共役の選択、共通数体の構成は[代数の章](algebraic-solving.md#実数の表現と最小多項式)で説明する。

### 多段の選択根を係数にする

`realtower` は親の順序体の上で一根区間を検査し、その実根βを加える。
元は親係数の有理式 `N(β)/D(β)` で表し、分母が選択根で非零であることを確認する。
定義多項式が可約でも扱えるため、各段の持ち上げで既約因子の計算を繰り返す必要がない。

例えば `(y-1)(y-2)` の根1を選べば、`y-2` の逆元は-1である。
この元は剰余環では零因子なので、剰余環全体での逆元を要求すると計算を閉じられない。
零判定は剰余の見た目で決めず、選択根における意味で行う。
定義多項式の次数も、真の体拡大次数や最小多項式の次数とは区別する。

一般の符号は、親の係数体上のSturm–Tarskiへ再帰して決める。
二次の定義では、共役を選ぶ区間と親の二乗比較だけで一次式の符号を決める経路も使う。
親の元は子へ明示的に埋め込めるが、別の共役・別の選択コンテキストは混在させない。
`orderedsturm` が返す相対多項式と一根区間も、一般の多段体の `Scalar` とは区別する。
設計と検査範囲は[代数塔](../research/realtower-20261116.md)と[独立レビュー](../research/realtower-independent-review-20261116.md)を参照。

## 一変数・二変数の制約

`realcad` は全実根を隔離し、根の点と根の間の開区間へ分割する。
各セルの符号と真偽を保ち、`witness` で存在する解、`counterexample` で全称式の反例を取り出す。
無理数の標本は問題の定義多項式と一根区間で表し、Sturmの根数で全根の被覆を検査する。
[半開端点の規約と独立オラクル](../research/realcad-20261116.md)に具体例がある。

`cad2` は全Collins射影を一変数CADへ渡し、各x標本の数体上で
[relativecad](../../src/relativecad)を使ってyを分割する。
全xセル・各y分割の被覆と元入力への束縛を検査し、先に内側y、次に外側xの量化を集約する。
`y=x` では∀x∃yが真でも∃x∀yは偽になるため、全標本を一つに潰して集約することはできない。

`semialgebraic` は、yを量化した各xセルの真偽を、代数的端点を持つ区間と孤立点の集合へ変換する。
円 `x²+y²=2` なら∃yの結果は `[-√2,√2]`、内側の厳密不等号なら `(-√2,√2)` となる。
端点が欠ける場合は接触する開区間を結合せず、穴を保持する。
この出力は厳密な区間集合である。量化なしの有理多項式式が必要な場合は、次の `realclosed` を使う。
二変数経路の検査範囲は[CAD](../research/cad2-20261116.md)と[区間集合](../research/semialgebraic-20261116.md)に記録した。

## 任意変数のCADと実閉体の量化消去

`realclosed.prepare` は、六つの符号関係、Boolean結合、存在・全称を持つ一階実数式を受け取る。
自由変数は先頭に置き、各量化子は末尾へ変数を一つ追加する。
兄弟の量化子には別々の新しい変数を割り当て、変数の捕獲を避けて量化子を先頭へ集めた形に正規化する。

[cadprojection](../../src/cadprojection)は変数数を固定せず、全係数、最後の変数の最高次項を順に除いた多項式（reducta）、
全対の部分終結式の主係数（PSC）を使う全Collins射影を作る。
終結式とPSCは [elimination](../../src/elimination)が計算し、その行列式には [berkowitz](../../src/berkowitz)を使う。
`berkowitz` は環上で除算を使わずに特性多項式・行列式・随伴行列を計算する部品である。
各段階を最終変数の導関数で閉じ、[cad](../../src/cad)は親セルの代表点で次の変数を特殊化し、その上の全実数直線を分割する。
無理数の座標も、多段の順序体に保持したまま次の係数に使える。
根集合は検査付きのモニックな最小公倍多項式で表し、因子の重複による中間次数の増大を抑える。元の原子多項式は符号判定用に保持する。
係数が特殊化で零になる場合も、全実根と開区間の被覆を検査する。

量化は内側の分割から順に畳み込む。全ての葉を一度に集約すると量化の交代が失われる。
自由変数が残れば、各セルの符号条件を結んだ**有理係数多項式の量化なしの式**を返す。
`quantifier_free` で式を取り出せ、自由変数がない場合は `truth` で真偽も取り出せる。
`run` の `Paused` とエラーは未完了であり、偽という結果にはしない。

三変数の球 `x²+y²+z²=1` からzを消去した式は、二自由変数の閉円盤を表す。
別の例では `x²=2, y²=x, z²=y` の正の証人を作り、zをさらに厳密に演算して `z⁸=2` を確認できる。
全セルの証拠は元の式・射影階層・親の係数体へ束縛し、返却した式も検査する。
[CADの実装と受入例](../research/cad-20261116.md)と[実閉体の式変換](../research/realclosed-20261116.md)を参照。

## 非線形実数SMTへ接続する

`realnlsmt.prepare` は、有理係数多項式の量化なしのBoolean制約を、補助変数を使うTseitin変換でCNFにしてCDCLへ渡す。
算術原子は多項式と関係の組で区別し、補助Boolean変数を算術原子として扱わない。
Boolean割当ての算術上の可否をCADで調べ、不可能ならその割当ての一部または全部を否定する理論節を学習する。
Boolean探索と逆単位伝播による反証検査（RUP）の基礎は[論理と制約解決](logic-constraints.md#cdcl)を参照。

| 探索の入口 | CAD側 | 理論節 | 理論衝突後のCDCL |
| --- | --- | --- | --- |
| `realnlsmt.start` / `start_core` | 枝刈りし、最初の厳密モデルで終了 | 元の被覆で証明できる範囲で原子を削減 | 状態を保持 |
| `realnlsmt.start_retained` | 同じ枝刈り | 算術割当て全体を拒否 | 状態を保持 |
| `realnlsmt.start_restarting` | 同じ枝刈り | 算術割当て全体を拒否 | 新しい探索を開始 |
| `realnlsmt.start_full` | 各Boolean候補で完全CADを構成 | 算術割当て全体を拒否 | 新しい探索を開始 |

状態保持では、`cdcl.run_incremental` が返すcursorを算術探索の間も保持する。
検査済みの理論節を `cdcl.add_clause` で追加し、学習節・trail・watchと証拠履歴を再利用する。
追加時だけでなくbackjump後も、追加節が新しい単位節になっていないか確認する。
再始動する二経路でも、検査済みの理論節は次の探索へ引き継ぐ。
設計と比較は[CDCL状態の保持](../research/retained-cdcl-20261117.md)を参照。

枝刈りは、親セル全体で真偽が確定した円柱の展開を省く。
[prefixlogic](../../src/prefixlogic)が未選択座標の係数を親の射影族へ対応付け、係数の消滅から一様な真偽を判定する。
短い証拠の葉も、元の式・射影族・検査済みの親セルへ束縛する。
`cad.start` と `realnlsmt.start_full` は完全CADの参照経路として残す。
[枝刈りの設計と検査範囲](../research/incremental-cad-20261117.md)に採用理由を記録した。

### 元の被覆から衝突節を削減する

既定の `start` は `start_core` を使う。
算術割当てが `A ∧ B ∧ C` で不可能でも、`A ∧ B` が不可能とは限らないため、原子を外す候補ごとに短い連言の不可能性を確かめる。
`cad.refute_on_cover` は新しい式の有理係数の判定計画を作り、**最初に得たCAD被覆**の木を走査する。
削減済みの木を次の候補へ使うと必要なセルを失う場合があるので、各候補は同じ元の被覆を使う。

候補の検査では、新しい射影、代数拡大体上の演算、根隔離、追加のCAD探索を行わない。
有理係数の計画構築と木の走査は行い、最終の厳密な証拠検査では射影と幾何を通常どおり再検査する。
元の短い葉の領域で新しい式の真偽が未確定なら、代表点だけから推測せず、その削減を拒否する。
実際には不可能な部分式でも、元の被覆が情報を持たなければ削減できない。
原子数が最小の核や、数学的に全ての不要な原子を除いた核を保証するものではない。
`core_probes` と `core_literals_removed` は試行と成功を別々に数える。
[衝突節削減の設計・反例・同条件比較](../research/theory-core-20261117.md)に詳細がある。

## 証拠が保証する範囲

| 結果・検査 | 確かめること |
| --- | --- |
| SMTのSAT / `check_model` | 元の式を厳密に満たす代数的座標とBooleanモデル。元の問題との一致も確認する |
| SMTのUNSAT / `check_refutation` | 各理論節のCAD証拠を元の原子へ結び直し、それらを加えた元CNFに対する最終RUP反証を検査する |
| `cad.check_cover(arity, formula, proof)` | 要求された式・変数数と証拠が一致し、対象の全原子多項式が射影自身のsourceに厳密に含まれること。そのsourceに対する全射影階層、根・兄弟セルの被覆、標本、符号、葉の真偽を再検査する |
| `cad.check` / `check_result` | 通常の `Problem` と証拠の式・射影の一致を保つ。`check_result` は返却した分解自体との一致も確認する |
| `realclosed.check_result` | 元の一階式、正規化、CADの量化消去証拠、実際に返した量化なしの式の一致を確認する |

共有被覆の余分な多項式は分割の補助であり、その等式や不等式を仮定するものではない。
`check_cover` が扱う上位集合の射影でも、射影は自身の全sourceに対して検査する。
通常の `prepare` が返した `Problem` へ別の射影を持ち込めるようにする変更ではなく、元の原子と係数計画の再構築、問題と証拠の束縛を維持する。
SMTの原式とBoolean符号化も再構築し、別問題の有効なモデルや反証の流用を拒否する。
[SMTの独立オラクルと改竄検査](../research/realnlsmt-20261116.md)に例がある。

`run` の燃料は外側の遷移回数であり、一遷移の実時間や割当量を固定しない。
燃料切れでは `Paused` を返し、エラーや未完了をUNSATへ置き換えない。
全Collins射影は残り、局所射影、算術側の探索状態や学習の再利用、仮定のpush/popは未実装である。
射影集合は大きくなり得て、密な高深度四次式などには重い計算が残る。汎用ソルバの実用的な規模を保証するものではない。
`prefixlogic`はANDだけから必須原子を集め、等号を使って他の原子を簡約する。
座標等式`a*x_i+b=0`を優先し、次数を増やさない二項等式にも同じ多項式除算を使う。
元の式を再構築する恒等式を確認し、定数の余りが元の関係に反する場合だけ全域の偽を導く。
`x=y, y=z, x²=2`から`z²≠2`の矛盾を得る例では、平方根の全枝の生成を省ける。
零因子や平方根の枝は勝手に選ばず、OR・否定の内側の条件を仮定しない。
元の式と全射影を保持し、checkerも元のsourceから再検査する。決まらなければ完全CADへ戻る。
簡約結果が矛盾判定や新しい帰結に使える場合だけ恒等式を再構築し、捨てる結果の検査は省く。
[採用条件と検査順序・計測の範囲](../research/cad-demand-20261121.md)を記録している。
[二項等式の適用条件・比較・限界](../research/cad-binomial-conflict-20261121.md)と、
[以前65秒未完了だった座標例の改善](../research/cad-linear-conflict-20261120.md)を参照。



Leanで証明しているのは、原子の観測が領域全体で健全だという明示的な仮定の下での、`prefixlogic` のBoolean部分の健全性である。
係数分解、射影、根隔離、CAD・SMT全体、MoonBitへの翻訳やコンパイラの形式証明ではない
（[対応と未証明部分](../../formal/REVIEW-prefixlogic.md)）。
有限の独立オラクル、問題ごとの証拠検査、Leanモデルの範囲と最新の横断検証は[検証ガイド](../VALIDATION.md)、
同条件の性能比較と削減できない入力の費用は[計測](../MEASUREMENTS.md)を参照。
