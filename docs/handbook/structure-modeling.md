# 構造を保持して算法を選ぶ

[ハンドブック](../../HANDBOOK.md) / [確率と情報幾何](probability-geometry.md)

この章は、検査した性質や構成過程を保存し、その後の演算で使うための設計をまとめる。
値を一度検査して汎用の行列・テンソルへ戻すと、利用側で検査や分解を繰り返し、既知の零や対称性も利用しにくくなる。

## 条件・由来・表現を分ける

| 型が保持するもの | 具体例 | 選べる演算 |
| --- | --- | --- |
| 検査した条件 | 正の有理数、正定値形式 | 安全な逆数、正の行列式、解が一意なsolve |
| 構成過程から従う関係 | Gaussian・指数型分布族のHessian構造 | 計量と3次cumulantからの曲率計算。専用の型は次段で実装する |
| 分解・表現 | 正のpivotを持つLDL、直和、正の定数倍、逆のview | 分解を共有するsolve、ブロック別演算、逆の逆の消去 |

`Semiring[A]` のような演算辞書は操作を揃える。結合則や可換則などの法則は、その辞書の利用条件として別に必要になる。
構造名を示すBoolだけを追加しても、その法則を使う計算の根拠にはならない。
検査済みの入力からだけ構成する、あるいは性質を保存する演算から構成する入口を設ける。

## 正の有理数と正定値形式

[positiveform](../../src/positiveform/positive.mbt) の公開型は外から構築できない。

`PositiveScalar` は正の有理数とその逆数を保持する。
構築時に正性を検査し、逆・積・自然数乗は正性を保つ演算として同じ型を返す。

`PositiveDefinite` は次の構成を保持する。

| 構成 | 不変条件と処理 |
| --- | --- |
| `Dense` | 正方・対称性を検査し、一度のSchur補元再帰で正のpivotを持つLDLを作る |
| `Inverse` | 元の正定値形式を保持する。applyとsolveを入れ替え、逆の逆は元を返す |
| `Scaled` | 正の係数と元の形式を保持する。連続する定数倍をまとめる |
| `Blocks` | 正定値な各ブロックを保持する。直和は平坦化し、solve/applyは各ブロックで行う |

`inverse`・`scale`・`direct_sum` は密行列の生成やLDLを行わない。
`matrix()` が明示的な展開境界となり、既存の汎用行列APIへ接続する。
`determinant()` は正の有理数の型を返し、直和では積、逆では逆数、定数倍では次元乗を使う。
零次元では行列式1、空ベクトルのsolveが成り立つ。

`Eq` は準備済み構成の一致を表す。線形写像としての一致は `equivalent()` で確認する。
これは共通の標準基底すべてへの作用を比較する。有限個の任意点の標本検査と異なり、線形性が既知なので作用素の一致を判定できる。

## 既存の利用側へ性質を渡す

Gaussianは共分散の正定値形式を保持し、`covariance_form` と `precision_form` から取得できる。
`gaussian_from_form` は既存の正定値構成を受け取り、再検査・再分解を行わない。
既存のモーメントAPIが必要とする共分散・precisionの密行列は一度生成してcacheする。
Gaussianの等号は平均・共分散・precisionの値で判定し、準備の構成やcacheを分布の同一性へ混ぜない。

一般の計量jetは引き続き不定値も受け付ける。
`riemann.positive_metric` は正定値な場合にだけ分解を保持した形式を返す。
この型が示すのは一点の計量の正定値性であり、計量場の平坦性やHessian性ではない。

## 次に由来を保持する場所

指数型分布族の基準分布と十分統計量、Gaussianの自然座標は、Hessian構造を与える構成過程を持つ。
汎用の点の `(g,T)` にはこの由来が残らないため、Hessian性を仮定する曲率経路への無条件な変換を設けない。
この由来を保持する型と曲率経路が、今回の次の実装段階となる。

対称テンソルの独立成分、交代形式の符号、既約多項式で作る有限体なども、構成が演算を制約する別の例となる。
それぞれ、何が検査済みか、何が構成から従うか、どの展開や演算を省けるかを明示してから専用表現へ移す。

## 検査の範囲

正定値構築は2次の対称整数行列を全列挙した首座小行列の条件、Gram行列、既存の別方式の消去法と照合する。
逆・定数倍・直和は値と構成の両方を検査し、形違い・非対称・特異・不定値・零次元も扱う。
型検査だけでLDL算法やすべての数学的法則を形式証明したものではない。
実際の速度・記憶使用量は別に比較し、構造を保存すること自体を未計測の高速化率へ読み替えない。
