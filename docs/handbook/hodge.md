# 構成を保つHodge演算

[ハンドブック](../../HANDBOOK.md) / [構造を保持する型](structure-modeling.md) / [確率と情報幾何](probability-geometry.md)

[hodge](../../src/hodge) は、固定した座標の正定値内積空間と向きを保持し、外積・和・内部積・線形作用・Hodge星を組み立てる。
係数には既存の有理多項式形式を使う。これは固定した内積での作用であり、点から計量場全体やその微分を復元する処理ではない。

## 元の空間の分解を使う

`Space` は検査済みの `PositiveDefinite` を受け取る。元の行列と向きが同じなら、LDL・直和などの構築が違っても同じ内積空間とみなす。
多様体の点やchartの識別子は含まない。`HessianTangent` のように点に結び付いた値からの移行は、成分を取り出す明示的な操作になる。

`PositiveDefinite.congruence()` は既存の分解から `g=F D Fᵀ` を取り出す。
`D` の各成分は正の有理数、`F` はせん断の積で、平方根は使わない。
密な入力はキャッシュしたLDLを使い、定数倍・直和・逆は構成から変換する。
逆のviewでは `F` を `F⁻ᵀ`、`D` を `D⁻¹` に変え、再分解しない。

せん断 `I+t E_ij` の外積上の作用は、`j` があり `i` がない基底について、`j` を `i` に置き換えた項を加える局所更新になる。
[forms.shear](../../src/forms/linear_action.mbt) は挿入・削除の偶奇から符号を求め、元の係数多項式は置換しない。
座標関数そのものを置換する `pullback` とは用途が異なる。

`PreparedHodge` は空間と次数だけを持つ。`binomial(n,k)²` 個のGram要素も、全 `binomial(n,k)` 基底も準備しない。
成分を求めるときは、`g⁻¹=F⁻ᵀ D⁻¹ F⁻¹` を外積上で作用させ、EuclideanなHodge補集合へ移し、向きと体積要素を掛ける。
作用列は行列積の順序と適用順序を区別する。`F⁻¹` は保存したせん断列の順に逆を、`F⁻ᵀ` は逆順に逆転置を作用させる。

大きさを決めるのは元の空間の分解と、実際に現れた中間項である。
最終結果自体が密なら `binomial(n,k)` 個の出力成分が必要で、せん断で中間項が増える場合もある。
任意の入力が次元に対して多項式時間になるという主張ではない。

## 外積を展開せず保持する

`HodgeForm` の内部表現は、成分のleafと、和・定数倍・外積・内部積・せん断・Hodge星の式からなる。
公開する演算は次数・空間を検査してノードを構築する。`parts()` が成分評価の境界となる。
構造としての等号と、成分を評価する `equivalent()` は区別する。

例えば `(dx+dy)∧(dy+dz)` は、和2個と外積の構成を保持する。
`parts_with(Factorized)` はせん断列で作用し、`parts_with(InteriorProduct)` は分解可能な1形式の外積に

```text
*(a ∧ b) = i_(b sharp) i_(a sharp) vol_g
```

を使う。内部積経路で扱う構成がない場合は、せん断列の評価へ戻る。
両者は同じ数学的な値を持つ別の評価経路で、1形式をsharpへ写す際も元の分解を使う。

二重Hodge星は `**alpha=(-1)^(k(n-k)) alpha` で簡約する。
`known_zero()` は構成から分かる場合だけ真偽を返し、不明は `None` とする。`is_zero()` は必要な場合に成分を評価する。
零倍や既知の零の外積・内部積は、不要な子の成分を計算しない。
現在の成分取得は形式全体の展開であり、任意の一成分だけを最適に求める評価器や、自動的な共通部分式のmemoizationは実装していない。

## 体積の平方根を保持する

有理数計量でも `sqrt(det(g))` は有理数とは限らない。
`Parts` は `a+b sqrt(det(g))` の2つの有理多項式形式を返す。積では平方根の二乗を `det(g)` へ戻す。
行列式の既約分子・分母がともに平方数なら、構築時に正の有理平方根を求め、2成分を通常の形式へまとめる。
それ以外では平方根が無理数なので、この2成分表現は一意となる。

向きの符号と正の体積の大きさは別に保持する。`volume_root()` は、要求したときだけ既存の実代数的数へ接続する。
向きや計量の異なる形式は、零であっても混ぜない。
Hodge星に対応する次数は `0..n`。負の次数を表せないため、この範囲外の零形式や外積も明示的に拒否する。

## 確認していること

106例の独立Fraction参照は、元の計量の外積行列を作り、それをGauss–Jordanで逆にして期待値を求める。
本体のせん断列と異なる算法で、非対角・有理平方根・無理平方根、次元0〜4、両方の向き、全成分と内積を比較する。
密な外積行列は、この小規模なテスト側にだけ置く。

追加の検査は、ご提示の分解可能な形式、2評価経路、強制的に成分化してからの二重Hodge星、体積の単位ノルム、逆・直和・定数倍の分解、Gaussian自然座標のFisher計量を含む。
24次元の12形式も、全基底を列挙せず疎な1項のまま作用させる。
せん断自体は次元5までの全888基底・添字対を、線形写像のpullbackによる別経路と比較する。

新しいHodge・せん断・評価グラフの法則をLeanで形式証明したものではない。
一般の計量場、曲がった多様体上の座標遷移、余微分、接続1形式・曲率2形式は対象に含めない。

## せん断の項併合

元空間のせん断 `I+t E_ij` では、同じ次数の整列済み外積基底のうち、`j` を含み `i` を含まないものだけが追加項を作る。
等しい大きさの基底集合の辞書順は、最小の対称差の要素がどちらに属するかで決まる。
全対象に共通する `j` を除いて `i` を加えても対称差は変わらないため、追加項も厳密な辞書順を保ち、追加項同士の基底重複は生じない。
この条件を使い、各追加項を元の列へ繰り返し挿入せず、整列済み追加列を一度作って元の項列とmergeする。
同じ基底の係数を加え、相殺して零になった項はその場で除く。

元の項数を `m`、追加項数を `a` とすると、**項列の併合で訪れる項数**は `O(m+a)` となる。
これは基底添字の比較・置換、単項ごとの符号計算、有理多項式の係数演算、せん断列全体の中間項の増加を定数時間とみなす主張ではない。
実測時間の改善率とメモリ使用量は未評価。
16次元の全120個の2形式基底を係数1で足した入力では、`i=15,j=0,t=1` による14個の相殺で106項となり、逆せん断で全120項へ戻ることを検査する。
