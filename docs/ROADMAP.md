# 到達点と次の候補

[ドキュメント](README.md) / [ハンドブック](../HANDBOOK.md)

現在の実装は、多段の実代数拡大、任意の有限変数のCAD、一階実数式の量化消去、
証拠付きの非線形実数SMTまでつながっている。独立レビューと、各3,775テストの3 backend統合検証を完了した。
設計上の接続は[厳密代数の計算経路](handbook/algebraic-solving.md)、検証済みの範囲は[検証ガイド](VALIDATION.md)を参照。

## 選択した本線：任意変数の実閉体ソルバと非線形SMT

2026-11-16、ユーザーがこの方向を選択し、時間上限を解除した。
直前の成果は各3,311テストの統合検証を終え、公開同期と作業木の片付けを完了した。

目標の入力は、有理係数の多項式の六つの符号関係とBoolean結合、有限個の変数と量化。
近似に置き換えず、解・反例・不可能性の根拠を検査できる形で返す。
資源不足は未完了として保持し、解なしへ置き換えない。

| 段階 | 実装済みのもの | 確認した範囲 |
| --- | --- | --- |
| 多段の実代数拡大体 | 選択根を順に加える係数体、厳密な四則演算・零判定・順序 | 有理数→α→β→γの計算と、別共役・別contextの拒否。独立Fraction・SymPy、既存二変数経路と照合 |
| 任意変数のCAD | 射影とliftingを変数列に沿って再帰し、全セルを被覆 | 3・4変数と複数量化交代の独立例、退化・共有因子・nullification、全証拠の入力束縛 |
| 量化消去 | セルの真偽を量化順序どおり伝播し、自由変数の解集合を表現 | SAT/UNSATだけでなく、量化の交代・境界・等価な別表現でも照合 |
| 証拠付き非線形SMT | 既存CDCLと厳密な実数理論を接続し、理論節の根拠を残す | 返却モデル、理論補題、最終反証をそれぞれ検査。小問題の全列挙とも一致 |

可約な定義多項式でも、選択根で分母の非零性を検査する有理式によって四則演算を閉じられた。
これを係数体として再帰liftingへ接続し、3・4変数の量化交代、複数自由変数のQQ式出力、
厳密モデルとCAD理論補題・RUPの検査まで実装した。
[受入例と検証範囲](research/cad-20261116.md)、[SMT](research/realnlsmt-20261116.md)を参照。

今後の不足は、全CADを作らずに済む増分的な局所射影と、密な高深度の体演算の費用削減。
これらは今回の入口の完成条件と分け、性能が確認できた変更だけを採用する。

[Jovanović–de Moura, Solving Non-Linear Arithmetic](https://dddejan.github.io/papers/jovanovic-ijcar2012.pdf)
は、非線形実数制約にCDCL型探索とCAD由来の射影を接続する参考になる。
証拠形式、今回のADTによる表現、性能上の採否は本プロジェクトで別途設計・検証する。

設計・検査・片付けの記録は[実閉体ソルバの作業記録](research/realclosed-20261116.md)へ残す。

## 別の遠い目標

| 目標 | 現在から使える部品 | 大きな不足 |
| --- | --- | --- |
| 分解体・Galois群・根号可解性 | QQ既約分解、共通数体、LLL | 厳密な複素根隔離、置換群、resolvent、非実根を含む代数拡大体 |
| 実代数集合の連結成分と経路 | CAD、実根、実解の一変数表現 | 特異点、セルの接続関係、roadmap |
| Schoof/SEAの楕円曲線点数計算 | 有限体、拡大体、多項式、楕円曲線、CRT | 除算多項式、torsion、Frobenius作用、traceの復元 |

Galois群の参考は[Stauduhar](https://www.ams.org/mcom/1973-27-124/S0025-5718-1973-0327712-4/S0025-5718-1973-0327712-4.pdf)。
原典は根の高精度近似も使うため、今回の制約では厳密な根隔離・有理区間による別設計が必要になる。
既存の `galois` パッケージは有限拡大体であり、QQ多項式のGalois群計算ではない。

幾何の参考は[Basu–Royの実代数集合のroadmap](https://arxiv.org/abs/1305.3211)、
点数計算は[Schoofの解説とAtkin–Elkiesの改善](https://www.numdam.org/item/JTNB_1995__7_1_219_0/)。
いずれも今すぐ完成すると見積もったものではなく、足場と不足を区別した候補である。
