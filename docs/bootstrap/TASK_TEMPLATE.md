# 並行探索タスクの契約

[ドキュメント](../README.md) / [探索・改善記録](README.md)

各タスクは目的、入力となる凍結API、変更範囲、期限、検証、成果物を持つ。
各workerは専用worktreeとbranchで作業し、成果ごとに自分の変更だけをcommitする。
共有mainへ取り込む操作はrootが行う。

- 核：独自Chain/Nat/BinaryとADT、パターンマッチ、再帰。数値型・リテラル・配列・可変状態・FFIなし。
- 比較：厳密な同じ結果。有限検証と全入力の証明を区別する。
- オラクル：テストと表示の境界だけに数値プリミティブを認める。
- 各成果：実装、独立オラクルまたは検査可能な証拠、適切なテスト、必要なら同条件ベンチ、考察。
- 共有README/HANDBOOK/計測一覧はrootが更新し、workerは専用のdocs/bootstrap断片を出す。
- 既存APIを変える必要があればrootへ連絡し、他workerの領域を直接編集しない。
- 公開・pushなし。取り込み後に変更が残っていないことを確認し、一時worktreeを整理する。

返却形式：commit SHA、追加API、実行したチェック、オラクルの根拠、残る制約、次の候補。
